Begin with [the programme report](programme-report.md), then follow the
[operator entry point](runbook.md). This is a bounded single-node developer
reference, with recorded model proposals and real native tools/providers.

1. Verify `distribution.sha256` and run the installed `fusion-verify-artifacts`
   against `distribution.json`. Match image configuration/manifest digests,
   chart, eight wheels and exact runtime source map. The detached
   [artifact record](../../evidence/phase3/artifacts.json) identifies the assembled
   packet; the packet does not contain a recursively hashed copy of itself.
2. Review [release gates](../../evidence/phase3/release-gates.json) and
   [source differences](../../evidence/phase3/dev11-dev12-source-delta.json).
   The 70-input core, ten-input continuation, fault drills and installation
   smokes are separate runs. Only explicitly named runs share retained state.
3. Check preserved early captures across source sequence 512, continued native
   work through 1,280 records, honest quota refusal and the uncertain mutation
   that remains charged. Session closure and archive do not reclaim allowances.
4. Check private native history/cognition, current raw/semantic denial, approved
   proper-excerpt publication, factual evaluation and actual next-context use.
   Fixture proposals never implement native effects or supply expected results.
5. Compare the original and fenced clone's fourteen sessions and 84 inputs.
   Review private-port denial/correction, old payload/history reconstruction,
   fresh credentials and execution refusal. No restore supplies replay credit.
6. Review the exact same-workflow chain artifact and independent effect readback.
   The failed pre-genesis claim remains separate from the explicitly selected
   fresh node. An artifact commitment is not a truth or freshness certificate.
7. Check protected-resource identity and task cleanup. Private archives, raw
   authenticated logs, credentials and keys are excluded. No public registry
   release, generative runtime, new approval or campaign slot spending occurred.

The operating envelope is finite. Provider-internal timing gaps, unestablished
CPU quotas, unobserved hosted CI, restricted source-build prerequisites and lack
of multi-node/production qualification remain visible. A second local virtual
environment is not evidence of a different human operator.
