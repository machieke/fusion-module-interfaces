## Responsibilities and compatibility

The implementation keeps state with the existing owners. The Registry interns
exact provider selections and seals bounded audit epochs. The application owns
session inputs, saved continuations, subscriptions, operator decisions and
reserved completion capacity. Search reclaims only eligible unpublished derived
indexes; application cleanup removes only verified reconstructible material.
Storage remains the authoritative payload/feed owner. Backup and handover tools
consume quiesced owner exports and authenticated ports rather than reading a
foreign owner's live database.

The browser gateway is a stateless client of the same scoped application and
operator ports, using its selected scoped credentials. The browser client
receives no Kubernetes credential, provider journal or provider credential. The independent Go implementation owns its own inspection
acceptance, result and completion journal, and computes the approved immutable
payload digest and length itself. Recorded model responses propose native
commands; actual native execution and owner effects supply the results.

New maintenance, Registry, clock, continuation and handover profiles are
explicit selections on fresh synthetic state. Historical profiles remain
available under their original semantics. No protected store is migrated.
Writable synthetic handover is a separate opt-in profile with current authority
outside the copied PVCs; default restore remains observation-only.

| Existing responsibility | Pilot addition and boundary |
| --- | --- |
| Registry | Interned immutable selections, finite audit epochs and control reserve; no renewed accepted binding |
| Application | Bounded subscriptions and prerequisite-aware continuations; no scheduler or new cognition |
| Search and application caches | Head-bound cleanup plans; authoritative payloads, captures and charges retained |
| Backup/operator | Base-plus-delta verification and explicit one-writer synthetic cutover; no automatic failover |
| Execution | Independent Go `inspect-atom/2` provider; no numerical translation or arbitrary execution |
| Browser | Scoped typed/native interaction and observation; no authority from UI state or cached results |

Native NAL/PLN mathematics, E5 preprocessing/model/vector semantics and retained
query views remain separately bound. Priority changes do not alter evidence
weight. A prerequisite read is an observation with an explicit race window, not
an atomic transaction across owners. Unknown, revoked, withdrawn and false are
different outcomes. A safe refusal is not positive task completion.
