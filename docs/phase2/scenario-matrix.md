# Bounded Phase 2 qualification matrix

This is the execution plan for the current programme, not passing evidence. Use two actual native agents, at most two preselected sessions per agent, 24 accepted inputs per session, four pending inputs and one child process per agent. The operator qualification caps its own submissions at 32 and observation time at 30 minutes. Each accepted input retains its original 120-second maximum; ordinary tool dispatch retains 30 seconds, and delegate uses the explicitly declared remaining input window. No observer renews either deadline. Recorded models propose commands only. Additional live generations: **0**.

The combined run is the bounded repeated-turn workload: 23 operator inputs plus four task/result inputs across A and B. Its native corpus is two logical memories and three immutable revisions (one supersession), followed by one withdrawal; administrative history atoms are counted separately. The scope/shared-writer diagnostics add two private and two shared opaque records only after native work is idle. No test changes the accepted input or tool limits. Record actual elapsed times and configured/observed owner memory and queue caps alongside these sample sizes; these samples are not an SLA.

Methods, scenarios, attempts and completed tasks remain separate in reports. The historical uncertain IRC-send and earlier campaign evidence remain separately labelled; a session API workflow is not a newly executed IRC workflow. Development failures retain their inputs and image identities. Final integrated evidence must come from one immutable source/image set; an accumulated union of development passes is not that gate.
