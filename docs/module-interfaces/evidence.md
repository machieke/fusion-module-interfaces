# M0 / M1 execution report — 2026-10-16

**M0 is complete. M1's bounded local integration is complete. Work stops before
M2.** The two peers are protocol fixtures. Payload storage uses actual DeTTa DA
libraries and persisted Reed–Solomon shares; a separate worker computes and
persists `inspect_atom`. An isolated, real F1R3node then commits the generated
result digest and reports canonical deploy effect finality. This is not a claim
that Omega Hive runs on ASI:chain or that a public network was tested.

## Design decisions and status

The [architecture](architecture.md) assigns one owner to atom metadata, payloads,
mailboxes, jobs/outbox, and each future cognitive state category. Backend-neutral
ports never import provider implementations. The DeTTa core was left unchanged;
application integration lives in this repository. DA scope binding uses generic
coordinate metadata, with no Omega/PLN/ECAN schema fields.

The [ADRs](decisions.md) adopt scoped immutable references, explicit semantic
idempotency, live local test authorization, separate receipts, SQLite FULL/WAL
and replay across the non-atomic DA/journal boundary. Full private episodes remain
client-side in the future design. Only deliberately shared generated bytes and a
result digest were used here. Numerical models, attention policy, production
authorization and the intended Hive release remain unresolved, not silently
selected. [Contracts](contracts.md) and `fusion/ports.py` specify C1–C4 without
implementing them or starting empty cognitive services.

## Guarantees observed and limits

The same contract suite demonstrated exact bytes/revision retrieval, no cognitive
dependency, ordered getMany, one logical result despite concurrent duplicates,
conflicting-key rejection, fail-closed version/profile/required-feature selection,
scope and route isolation, live revocation, and no public foreign-owner setters.
Expired work cannot start; accepted requests can recover their original receipt
after deadline/acknowledgement loss. Full inboxes retain completion in the outbox
and excess jobs receive OVERLOADED instead of disappearing.

Actual SIGKILL tests covered acceptance-before-response, result-DA-write before
journal commit, and completion commit before dispatch. A restarted caller recovered
status/result and correlated completion. Removing cached DA payload plus two
shares still allowed reconstruction; a third missing share or corrupt share
returned NOT_AVAILABLE. A fabricated/missing ref returned the appropriate explicit
error. Same-principal scope authorization and raw provider scope binding were
both exercised. Direct DA lock contention returned OVERLOADED.

Limits: same-host trusted OS user; local fixture credentials; no production SCS
authorization or multi-tenant process isolation; no encryption/privacy claim for
the deliberately public fixture DA profile; no cross-store atomicity, power-loss,
disk-loss or Byzantine fault test; no retention/GC guarantee; no exactly-once
physical computation. DA replay may leave an unreferenced artifact. The actual
wire provider supports 1.0.0; additive 1.2.3 compatibility is a resolver fixture,
not a deployed future-version provider. The signing adapter pins one registered
fixture and is not an arbitrary deploy service.

## Blocked or deferred gates and stopping point

Actual Hive integration remains blocked by the missing intended runtime checkout
and version/registry selection. MeTTaClaw's inspected channel cannot supply the
required durable/scoped handoff without adaptation. Production authorization,
distributed DA custody, multi-validator/public-chain operation, independently
verified proof evidence and a meaningful load baseline remain open; the local
gates above do not pass them. DAS and ECAN/PLN integration are deferred cognitive
work, not failed M1 substitutes.

The next bounded milestone is **M2: private ordered episodes plus duplicate-safe,
lineage-aware belief revision using a reviewed existing numerical profile**.
Its contradictory-evidence and numerical golden tests are specified, not executed
as new functionality here. No implementation work beyond M1 was started.
