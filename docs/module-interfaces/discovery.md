## Glossary and anti-glossary

| Term | Meaning here / must not be confused with |
|---|---|
| AtomSpace / AtomStorage C0 | Scoped immutable typed envelope storage in this profile; not a universal ontology or replacement for OpenCog/DAS. |
| Episodic memory | Private ordered observation/action/result provenance; an assertion occurrence is not its truth. |
| PLN | Identified upstream probabilistic rule/revision semantics; not any weighted average. |
| ECAN / STI / LTI | Attention owner / short-term importance / long-term importance; C3 proposes STI only; LTI promotion deferred. |
| DA | Availability/persistence of opaque bytes under a stated provider guarantee; not cognitive interpretation or indefinite storage. |
| Omega Hive | A family of evolving agent implementations; these protocol fixtures are not Hive agents. “John's Hive” does not select an exact revision. |
| ASI:chain | Optional chain execution/commitment substrate; DeTTa local files and a local-only mailbox are not ASI:chain. |
| Interface / implementation / transport / placement | Behavioral contract / its provider / communication binding / deployment location. A service contract need not be a smart contract. |
| Accepted / persisted / delivered / executed / included / finalized | Separate observations; never a universal success flag. “Callback” is correlated completion, not continuation migration. |
| Evidence / confidence / consensus | Occurrence provenance / numerical interpretation / distributed agreement; none substitutes for another. |
| Transcript aliases | “64 bits/64 bytes” and variant naming unresolved; no architecture depends on that transcription. |

Definition of ready: owner, operations, profile, dependencies, acceptance cases
and stop boundary explicit. Done for a gate means executed evidence matches its
advertised guarantee; a fixture or future test specification does not pass a
real integration gate.
