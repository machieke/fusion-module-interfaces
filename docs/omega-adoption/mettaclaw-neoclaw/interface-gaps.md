# Interface and profile decisions

These decisions concern a future adoption design. Nothing in this packet changes a Fusion profile or claims MeTTaClaw conformance. Source identities and per-symbol evidence are in [the ledger](mapping-ledger.json) and [component view](component-map.md). Existing Fusion contracts are the pinned [ports](https://github.com/machieke/fusion-module-interfaces/blob/33388d20cb10c5f9878a463a6d0debba7949e35a/fusion/ports.py), implemented validators and selected descriptors, not the broad family names.

| ID | Observed mismatch and affected symbols | Decision | Compatibility / recovery consequence |
|---|---|---|---|
| G01 | `forget`, `update`, Chroma delete, `remove-atom` mutate or remove records; Fusion AtomStorage creates immutable scoped bytes. `update` allocates a new UUID, deletes the old record before reading its STV. | **Defer product decision; keep mutations local.** A future explicit supersession/tombstone contract would be additional behavior, not `AtomStorage.delete`. | Logical forgetting, physical erasure, retrieval exclusion and executable-space removal are different promises. Immutable bytes cannot silently promise erasure. No migration or repair of existing memory is specified. |
| G02 | `query` embeds text and vector-searches, then promotion-ranks. M5 `exact-attributes/1` admits only canonical `application/fusion-knowledge-v1` records and 1–3 exact scalar predicates on kind/topic/label. | **New named profile**, DRAFT `semantic-embedding-memory/1`, plus separate Embedding interface. | Must pin model revision, dimensions, normalization, distance, tie order, k/caps, source feed, freshness and pagination. Current Chroma has no replayable accepted feed. Exact Search can serve only newly enrolled exact records; it cannot substitute for today's query. |
| G03 | `get-promotion`, `promote`, `demote`, promotion SQLite use real scores and wall-clock power decay. | **New named profile**, DRAFT `wall-clock-promotion/1`; local initially. | Existing `sti-additive-linear-decay/1` / closure profile has integer units, logical steps, causal receipts and strict deadlines. No clock retiming, STI substitution or claim of implemented LTI. Future profile must specify backward clock movement, ties, saturation and retry identity. |
| G04 | `tvUpdate` links timestamp then overwrites Chroma STV. Same episode can revise repeatedly; contrary evidence is not retained independently. | **Split C1 provenance from C2 admission**, with a separately selected NAL numerical profile if preserving its mathematics. | Fusion `pln-revision-private/1` and `pln-derived-private/1` retain roots, independent/alternative evidence and revision CAS. Its guarded PLN runtime is not MeTTaClaw `Truth_Revision`. Existing STVs do not reveal their missing evidence history. Do not infer independent roots or import them as new observations. |
| G05 | `linkedEpisodes` is a list of timestamp strings; `link` has no endpoint/schema validation; `unlink` mutates it. | **Compatibility facade + typed identity design; defer retraction semantics.** | M5 `schema-ordered-relations/2` supports assert/get/outgoing/incoming, ordered roles and scoped atom endpoints. C1 EpisodeRef is not an AtomRef: a new immutable episode-handle payload and declared relation schema would be needed. No implicit string-to-ref cast; no existing unlink port. |
| G06 | `appendToHistory`, `getHistory`, `around_time` operate on flat text and nearest physical lines. | **New append design using C1; legacy text facade kept local.** | C1 has explicit episode identity, expected sequence, evidence refs and durable pending deliveries. A ±20-line window is not equivalent to an episode page. No existing history is parsed into invented authoritative events. |
| G07 | `metta` permits arbitrary evaluation; shell/file tools inherit host authority. A Prolog inference limit and external shell timeout do not bound all effects. | **Keep general execution local; named profiles only for selected operations.** | Current DelegatedExecution is `inspect-atom/2`, operation literal `inspect_atom`. It cannot execute NAL, web queries, shell or file mutation today. Named future execution needs schema, sandbox, path/network policy, byte limits, deadline, durable identity and honest ambiguous-effect behavior. |
| G08 | IRC/Mattermost last-message strings consume on read; `send` returns success without durable acknowledgment; Mattermost seen IDs are volatile. | **Split durable Messaging owner from transport adapter.** | `durable-mailbox/2` provides acceptance, repeatable poll/ack, scoped routes and outbox recovery. It cannot create an IRC server delivery receipt or reconstruct lost ingress. Transport receipt, mailbox acceptance and application processing acknowledgment must remain distinct. |
| G09 | `getSkills`, `LLM_COMMANDS`, `configure`, provider `if` branches and git imports have no versioned requirements. | **Use Registry/Resolver as future consumers; add ToolDescriptor interface.** | Fusion Registry is provider metadata, not a tool catalogue. Resolver matches version/profile/operations/guarantees/privacy; a hardcoded name is not selection. Prompt documentation must never grant authority. Current resolver has no verifier-backed selection mode (`verification != none` is rejected). |
| G10 | API keys, bot tokens and CLI settings authenticate the process to upstream services, not each human/model tool request. | **Trusted local caller/route mapping plus Authorization consumer.** | Caller principal cannot be supplied by model text or a display name. Preserve current policy checks on submit/read/replay/ack. API secrets stay in operator configuration; grant a service scoped delegation, never send environment variables as tool arguments. |
| G11 | NAL truth functions, `\|-nal`, `\|-`, `\|-nal7`, `\|-t` cover many rules with floating arithmetic and broad patterns. Fusion selected kernel is grounded five-premise deduction on a different pinned PLN runtime. | **New named NAL profile** for one rule; retain broader rules locally. | Pin source/runtime and decimal/float serialization, premise order, allowed AST, guards and output shape. Keep pure math separate from C2 admission and C4 selection. Do not invent replacement mathematics or claim same-profile provider substitution across NAL and PLN. |
| G12 | Random UUIDs, second-resolution local timestamps, Mattermost post IDs and display strings differ from scoped AtomRef/EpisodeRef/EvidenceRef identities. | **Compatibility facade with explicit identity ownership.** | Timestamp resolution is one-to-many. Reject ambiguous mutation targets in a future safer profile; this is a documented compatibility change, not exact preservation. Never mint provenance or authority from a timestamp/hash alone. |
| G13 | Cwd-relative files, global Python clients/connections, PeTTa spaces, multi-step writes and volatile counters assume one process/filesystem. | **Split owners and specify bounded recovery before remote placement.** | No shared remote DB mounts or cross-owner transactions. Stable request identity must be persisted before submission; each owner commits its own receipt/outbox. Interrupted work can be partial or unavailable. Retrying without identity must not masquerade as safe replay. No populated-state migration in this task. |

Additional capabilities outside the bounded denominator:

| ID | Missing interface | Required semantics; existing-family limit |
|---|---|---|
| X01 | ModelInference | Model/provider revision, text/image input schema, context limits, token/cost budget, cancellation/deadline, nondeterminism and saved response identity. Existing kernel is logical rule application, not LLM completion. A future named execution wrapper does not eliminate this contract. |
| X02 | Embedding | Immutable model identity, dimensions, normalization, distance compatibility, batching, deterministic/reproducibility policy and vector privacy. Search consumes embeddings; it does not silently own model generation. |
| X03 | Perception / media acquisition | Media source/consent, capture time/identity, sampling/reset semantics, resource/deadline bounds, retention and delivery. Optical-flow heat decay is not STI. Image files are not C1 episodes until explicitly admitted. |
| X04 | Agent orchestration / working task context | LLM wake loop, prompt construction and intended `pin` working memory. Actual `pin` is a no-op. These are application responsibilities, not a new Fusion family or C4 conformance. |
| X05 | ToolDescriptor / skill catalogue | Typed arguments/results, effect and private-data declaration, caller policy, error schema, versioned vocabulary. Registry can select the backing provider, but its descriptors do not describe the complete user-facing tool semantics. |
| X06 | Execution policy / sandbox contract | Working directory/path allowlist, symlink handling, subprocess/network restrictions, output/resource limits, effect classification and current identity. Neither arbitrary MeTTa nor `sh -c` is remote-safe today. |
| X07 | External web-search operation schema | DDGS query/results/deadline/encoding/error contract. A bounded named DelegatedExecution profile is sufficient as the host family, but is absent today. This is not Search projection over owned knowledge. |

All DRAFT names in this packet are review labels only. Existing private profiles remain `private-local-only`; a remote deployment needs an explicitly compatible new privacy/transport contract, not a relabelled descriptor. [Seam contracts](seam-contracts.md) specify the candidate cuts; [the scorecard](remote-placement.md) ranks them.
