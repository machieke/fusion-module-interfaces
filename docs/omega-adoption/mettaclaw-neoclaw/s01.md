# S01 — one native NAL truth deduction, with replaceable placement

S01 implements **only** `neoclaw-nal-truth-deduction/1`, named operation `nal_truth_deduction`: two grounded STVs in, one original native `Truth_Deduction` result out. The original MeTTaClaw command, adapted local command and adapted authenticated HTTPS command return the same string:

```text
metta (Truth_Deduction (stv 0.8 0.9) (stv 0.7 0.8))
→ (stv 0.5599999999999999 0.4032)
```

This is one adopted operation, not the whole PLNKernel family, NAL rule engine or Omega. Broader NAL/MeTTa commands remain on the original local handler. There is no fallback for the selected operation, belief admission, memory access, inference-control action or chain work.

**Executable contract and placement.** [neoclaw_contracts.py](../../../fusion/neoclaw_contracts.py) defines the closed DTO, pure `TruthDeduction.applyTruth` port and selected descriptors. The execution envelope uses interface version `1.1.0`, this named profile, source/runtime/kernel selection tokens, scope `generated-s01`, `sharing=generated-shareable`, stable request/correlation/route identity, absolute deadline and bounded attempts. Each premise has exactly `strength` and `confidence` as numeric lexical strings. The admitted domain is `0`, `1`, or decimal `0.x` / `1.000…` with 1–17 fractional digits, within [0,1]. Variables, NaN/infinity, expressions, extra arguments, imports, paths and function selectors are rejected. Input exponent notation and negative zero are outside this profile. Native output scientific notation is retained when the pinned runtime emits it. Numeric lexical strings preserve the original integer/float parsing and representation; Python only validates structure/range, never computes deduction.

The local `metta` facade recognizes the named expression and converts it to that DTO. Only trusted composition reads a local config path; no expression or path crosses HTTPS. The native command driver creates a temporary, checked replacement of the **one** upstream `metta` definition; its other branch is the original local body. Original checkout files remain unchanged. The original and adapted paths run real MeTTaClaw parsing, native evaluation and the actual skill handler. The outer single-command ingress/capture is test scaffolding; full `run.metta`, LLM ingress, wake loop and channel/Chroma startup are **unrun**.

`neoclaw_transport.binding` alone selects in-process invocation or certificate-verified TLS/TCP. Caller business logic and the adapted skill bytes are identical. Network tests use a separate loopback HTTPS server process, real native operator processes and a native caller in a bubblewrap filesystem namespace that hides both provider state and the older user Omega checkout. Transport is **same-host isolated**, not multi-host; local stdio is not counted as network evidence. The listener and client profile permit only `127.0.0.1`. Every module call requires a generated bearer credential and current server-side policy; unauthenticated requests, stale selection, wrong scope/route/principal and private placement fail. TLS verification is exercised with both trusted and wrong CAs. No public service remains running.

**Owners and independent commits.** The new fixed execution composition reuses M1 `ExecutionOwner.read/flush`, `AtomOwner`/`AuthorizedAtoms`, real DeTTa opaque storage, `MessageOwner`/`MessagingSession`, `Policy`, descriptor resolution and receipt validators. Its pure kernel executes pinned original MeTTa; the kernel owns no job, receipt or belief state. The caller accesses only declared operations. Test-only observers and corruption fixtures inspect generated journals; production caller code never reads foreign databases.

| Commit / authoritative owner | Durable effect and recovery |
|---|---|
| Caller intent | Saves request identity, canonical request, profile/selection, deadline and RPC budget **before** dispatch. A changed intent or changed budget under the same key conflicts. |
| Execution acceptance | Job, mutation receipt and work record commit together. Lost acceptance reply replays the same job after a real server kill. Current authorization still applies. |
| Execution attempt reservation | Spends one native attempt before computation. Kills never refund it. Pure computation may repeat after death before its output commit. |
| Execution numerical output | Saves the validated original native representation independently of AtomStorage. Recovery can finish already-computed work after the deadline without starting new mathematics. |
| AtomStorage / DeTTa | Persists result bytes and immutable metadata under a stable operation subkey, independently of execution terminal state. Replay returns the same logical result reference/receipt. |
| Execution terminal state + outbox | One owner transaction records success/failure and its completion. This is later than payload persistence and earlier than mailbox delivery. |
| Messaging acceptance | Accepts the completion independently; death before the execution outbox is marked sent causes duplicate delivery of the same logical message. |
| Caller completion receipt | Verifies request/profile/runtime/selection, exact result hash/reference, truth representation and matching completion; commits before mailbox acknowledgment. |
| Messaging acknowledgment, then caller ack marker | Separate commits. Repeated native command replay reauthorizes and acknowledges the same delivery without another logical job/result/receipt. |

Independent databases are required; populated non-S01 execution journals are rejected without migration. SQLite owners use WAL/FULL. Native reservations are bounded at three; caller RPC reservations at 64; native invocation at five seconds or remaining deadline; each HTTPS call at one second. Input/result payloads are bounded at 4096 bytes, pending queues at configured capacity, and accepted requests at 128 lifetime rows per execution/caller journal. All these are finite **process-restart** bounds, not power-loss or distributed failover guarantees. Deadlines are never renewed. A deadline blocks new mathematics; it does not erase completed work or forbid reading/closing it. Persisted output can finish after expiry. Exhausted caller budgets stay exhausted even after a malformed receipt is repaired. No automatic refund, garbage collection or new request is manufactured to hide that outcome.

One unfinished intent per reply route is the supported composition. An unrelated delivery is refused and left unacknowledged. Current authorization is checked on submit/replay, owner work, reads, polling and acknowledgment; this is not a global transaction between the policy file and all owners. A result's structure, digest and binding are validated; this is not cryptographic proof that a malicious provider performed the arithmetic. Original-source execution and native comparisons provide the numerical evidence for the tested provider.

**Executed coverage.** The final gate report distinguishes 13 fixture-focused S01 contract tests from 19 integration test methods using real native MeTTa, real DeTTa and actual HTTPS. Generated STVs, credentials, CA, failpoint coordination and deliberate corruption remain labelled fixtures. Boundary comparisons include zero/one, integer versus float representation, rounding-sensitive decimal input and very small values rendered in scientific notation. Broader `metta (+ 1 2)` stays local. Failure of the network provider produces no local fallback.

The SIGKILL matrix covers five native caller commit boundaries, six worker/delivery boundaries and lost HTTPS acceptance. Additional tests kill after native reservations until the durable budget is exhausted, kill caller RPC reservations until exhausted, expire a reservation across a kill, and finish persisted output after expiry. Repeated native replay retains one job, one result atom, one logical completion and one caller receipt. The after-compute kill deliberately permits repeated physical mathematics; no exactly-once execution claim is made. Revoking ack authority after a durable native caller receipt leaves the message unacknowledged until authority is restored. Malformed bound payloads and receipts do not become successful results. The report preserves resolved development failures rather than rewriting them as original passes.

The final full S01 run passed **32 tests**. Existing regressions passed **156 core tests**, **46 native-provider tests** and **42 authenticated native Hive cases**, with no skips. Real-chain execution was not run. Complete commands, case names, logs, source checks and resolved development failures are preserved in the gate report.

**Reproduce the supported gates.** On Linux, use Git, uv, CMake, Ninja, a C/C++ compiler, SWI build prerequisites (GMP, zlib, OpenSSL, libedit, PCRE2, libyaml and libarchive development libraries), OpenSSL CLI, bubblewrap/user namespaces and Rust/Cargo for DeTTa. The native command needs only the built Prolog-to-Python Janus bridge and Python standard library: no model, embedding, Chroma or channel SDK credentials. The build fails if Janus is unavailable. Exact tested tool versions are in the build manifest.

```bash
uv run --python 3.11 --locked python scripts/build_s01.py artifacts/s01/native-fresh
S01_RUNTIME="$PWD/artifacts/s01/native-fresh/runtime.json" \
S01_DETTA="$PWD/artifacts/m5/reproduction-01/providers/detta/target/debug/fusion-detta-adapter" \
S01_EVIDENCE="$PWD/artifacts/s01/repeated" \
uv run --python 3.11 --locked python -m unittest -v \
  tests.test_neoclaw integration.neoclaw.test_s01 \
  integration.neoclaw.test_network integration.neoclaw.test_recovery
```

The build destination must be empty. Git/uv download caches may be warm; objects and venv are freshly built. If the verified DeTTa build is absent, obtain the pinned `secured-contract-spaces` revision above, verify a clean checkout, and run the unchanged `scripts/build_detta.py` with `DETTA_REPO` pointing to it, then use its reported binary as `S01_DETTA`. This existing recipe uses the checked-in Cargo lock and offline dependency cache; an absent source or uncached Rust dependency is a **blocked prerequisite**, not permission to select the file fixture. The S01 native test setup fails on a missing runtime/DeTTa binary. Existing complete M1–M3 build recipes remain in the [Fusion runbook](../../module-interfaces/runbook.md); they do not change this S01 profile. No legacy PLN runtime file was edited for S01.

The integration tests generate isolated mode-0700 roots and mode-0600 operator/caller configs, certificates and request identities; these secrets are never committed. `integration.neoclaw.host serve` exposes only `submit/status/result/get/poll/ack`; trusted local `work` and `flush` entrypoints drive a single bounded operation. There is no remote operator/eval endpoint and no scheduler. Configuring `--caller-config` selects the adapted native command; changing `placement` and its binding switches transport. Identity/deadline/budget are preserved on replay; a separate intentional request must receive a new operator-supplied identity.

**Limits and stop boundary.** No multi-host, public-network, power-loss, compiler-bit-reproducibility, empty-global-cache, kill-at-arbitrary-native-instruction, full Omega startup, hosted provider or live-state migration gate is claimed. M4 real-chain regression is deliberately **unrun** under this task's no-chain scope; its fixtures and unchanged source remain separately reported. Missing full Omega dependency/provider pins remain future prerequisites, not blockers to this bounded native command. No old mapping row/family classification is promoted, no private Omega store was read, no existing cognition owner/PLN profile was changed, and no new presentation or extra rule was implemented.
