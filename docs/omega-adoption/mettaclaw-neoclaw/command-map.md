# Commands, ordered composition and compatibility facade

The source advertises **19 command names** in `helper.LLM_COMMANDS` and `getSkills`. `receive` is a runtime command; library reasoning, model/embedding/vision and persistent-space operations are additional callable surfaces. This table covers all of them. Exact definitions and calls are linked through the [component map](component-map.md) and [327-occurrence symbol index](symbol-index.json).

**Today:** these are ordinary MeTTa/Python/Prolog calls, not Fusion port invocations. **Target:** the following `OmegaModuleFacade` is a local design only. Every DRAFT profile is unimplemented. A request journal mentioned here is a requirement for a later chosen slice, not infrastructure added by this task.

Common facade rules: trusted caller context and operator policy stay local; resolve and bind a complete provider descriptor before invocation; persist operation identity, exact arguments/digest, profile/selection, original deadline and correlation before any mutating submission. Derive stable per-owner subkeys. A timeout means unknown/pending until the owning provider resolves it. Replays retain keys and deadlines and recheck current authority. A changed intent with an old key conflicts. There is no cross-owner transaction and no manufactured success after an error. No automatic local fallback.

Additional callable/imported surfaces:

| Surface | Actual responsibility and proposed boundary |

| `embed`, `initLocalEmbedding`, `useLocalEmbedding`, `useGPTEmbedding`, `useOpenRouterEmbedding` | Out-of-inventory Embedding. Local E5 and hosted OpenAI paths differ; imported OpenRouter embedding is callable but not the main memory selector. No automatic provider interchangeability. |

| `add-atom`, `remove-atom`, `get-atoms`, `bound-space!`, `export!`, import of &persistent | Mutable executable space plus non-atomic persistence. Keep local; no immutable AtomStorage or safe remote code contract. |
| `invoke_tool(name,arguments)` (proposed facade only) | Local typed allowlist dispatch to a **specific** selected tool profile; unknown names fail. It is not a remotely exposed generic execution API. Local application owns correlation, each provider owns acceptance/results. |

The target changes failure semantics where current tokens overstate success. Such changes must be opt-in/versioned and tested; “compatibility facade” does not mean every legacy behavior can be preserved. [Seam contracts](seam-contracts.md) define exact candidate requests, receipts, boundaries and limitations.
