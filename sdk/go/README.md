# Bounded Go contract client

This independent Go 1.18 stdlib implementation calls the existing
`omega-native-sessions/3` and immutable AtomStorage/feed ports. It imports no
Python or native owner implementation. Go was already installed; TypeScript's
compiler was unavailable. No external package download is required.

```sh
GOPROXY=off GOSUMDB=off CGO_ENABLED=0 go test ./...
GOPROXY=off GOSUMDB=off CGO_ENABLED=0 go build -trimpath -o omega-client ./cmd/omega-client
./omega-client --config private/session.json --action allocate \
  --identity explicit-intention-01 --template shared --deadline-ms ORIGINAL_BOUND
./omega-client --config private/session.json --action submit --session ACCEPTED_UUID \
  --identity input-01 --text 'query synthetic compass' --deadline-ms ORIGINAL_BOUND
./omega-client --config private/session.json --action observe --session ACCEPTED_UUID \
  --content --deadline-ms OBSERVATION_BOUND
```

Configuration selects `fusion-go-client/1`, kind `session` or `atom`, the exact
contract, scope, principal, HTTPS endpoint, CA file and scoped credential file.
Session operations additionally select actor `operator`; AtomStorage selects
the descriptor and composition. `server_name` permits an explicitly selected
local tunnel while validating the original service DNS certificate. Credentials
are provisioned separately. The binary receives no kubeconfig or provider key.

Each CLI request exits; callers retain accepted identities and original owner
deadlines in their own application. An observation bound grants no execution
extension. The client never retries a transport exchange, cancels work by
closing a connection, resubmits an uncertain effect, or falls back to another
provider. Metadata binding may require a role grant the ordinary operator does
not have; allocation already carries selected metadata. Permission is not added
automatically for discovery.

`testdata/golden.json` is a normative wire sample generated by the existing
Python canonical contract/descriptor functions, not a fixture answer. Tests
validate canonical bytes, descriptor/request digests, strict duplicate-key and
Unicode handling, exact integers, TLS correlation, unknown fields/states and
lost-reply behavior. Real endpoint qualification is separate from these
explicit HTTP fixture tests. Scope is a small typed client subset, not a
second native Omega, inference implementation or complete module SDK. Browser
and multi-host operation are unrun. Floating-point request fields are refused;
opaque stored bytes, including their numeric representation, remain exact.
